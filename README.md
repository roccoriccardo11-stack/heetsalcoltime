# HEETS ALCOL TIME · Pinzolo & Madonna di Campiglio

Web application moderna per la promozione, organizzazione e gestione degli eventi, feste, après-ski e momenti in quota a **Pinzolo** e **Madonna di Campiglio**.

## Caratteristiche

- **Design Esclusivo Alpine Nightlife**: Grafica dark con accenti caldi ambra/oro/arancio, ispirata allo stile *fiesta-vibes-central*.
- **5 Categorie Dedicate**: Feste/Collette, Après-ski, Capodanno, Ferragosto, Montagna (con schede, descrizioni e gallerie dedicate).
- **Calendario & Liste Eventi**: Eventi in programma e storico passato con sistema di richiesta accredito/lista anche via WhatsApp.
- **Galleria Fotografica con Moderazione**:
  - Gli utenti/turisti possono caricare foto scegliendo la categoria.
  - Le foto caricate vanno in una **coda di moderazione**.
  - Gli amministratori possono **approvare** (pubblicandole nella gallery pubblica) o **rifiutare** ogni foto.
- **Pannello di Gestione Admin (CMS Integrato)**:
  - Riconoscimento automatico del ruolo al login.
  - Creazione, modifica ed eliminazione eventi.
  - Moderazione foto in tempo reale.
  - Editor di TUTTI i testi del sito (Hero, Chi Siamo, Categorie, Contatti, Social) direttamente da browser senza toccare il codice.
  - Inbox richieste liste e messaggi di contatto.
- **Accessibilità & Demo Rapida**: Pulsanti 1-click per testare il ruolo Admin o Utente.

## Come Avviare il Sito (2 Modi)

### Modo 1 (Più semplice - 1 Click):
Fai semplicemente **doppio clic sul file** [AVVIA_SITO.bat](file:///c:/Users/Utente/Desktop/HEETS%20ALCOL%20TIME/AVVIA_SITO.bat) presente nella cartella del progetto. Aprirà automaticamente il browser sul sito!

### Modo 2 (Da Terminale / Prompt dei Comandi):
```bash
# Apri il terminale nella cartella del progetto e digita:
npm run dev
```
Poi apri il tuo browser all'indirizzo: **`http://localhost:5173/`**
